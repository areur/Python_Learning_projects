Machine Learning related projects. I had originally followed this 17-week curriculum I prompted from Gemini where I'd read from *Mathematics for Machine Learning* and do a Kaggle lesson then make a project every week

The projects are as follows
- **Linear Transformation Mapping Tool**: visualizes how certain transformation matrices change the shape of a space
- **k-NN Nearest Neighbors Classifier**: Finds distance between points using ddifferent norms and then predicts a class for that point
- **Normal Equation Solver**: Solves for linear regression using the Normal Equation learned in the Linear Algebra Projection unit of *Mathematics for Machine Learning* $\lambda=(B^\top B)^{-1}B^\top x$
- **Housing Price Pipeline**: Full ML pipeline that loads in a data set, pre-processes the data, uses my custom Linear Regression class to create a prediction and cross-validates the predictions
- **Analytical Gradient Solver**: Derives the gradient of a single neuron's loss function using AutoDifferentation
    - **Autodiff Finite-Difference Engine**: Extension to the previous project, uses finite-differences to calculate the gradient and compares it to the other answer (interesting name Gemini gave it)
- **Gradient Descent Visualizer**: Implemented a Stochastic Gradient Descent optimization loop for the previous Project and visualized how the model changed over its training epochs
- **Binary Classifier**: Modified the previous project to be used for Binary Classification instead of Linear Regression.
